# 실제 서비스 오픈(Production) 전 필수 수정/체크 리스트

현재 프로젝트는 핵심 디자인(UI/UX)과 주요 기능들의 흐름을 잡기 위해 **'테스트(Mock) 모드'**로 개발되어 있습니다. 정식으로 서비스를 오픈하고 고객의 실제 결제를 받기 위해서는 아래 항목들을 반드시 실제 시스템으로 교체해야 합니다.

## 1. 🔐 회원가입 및 로그인 시스템 (인증)
- [ ] **실제 회원가입 페이지 신설:** 현재 누락되어 있는 회원가입 폼(`/signup`)을 만들고 이메일, 비밀번호, 이름 등을 입력받아야 합니다.
- [ ] **비밀번호 암호화:** 이메일 로그인 시 입력한 비밀번호를 데이터베이스에 안전하게 암호화(예: `bcrypt`)하여 저장하도록 인증 로직(`src/lib/auth.ts`)을 교체해야 합니다.
- [ ] **임시(Mock) 로그인 삭제:** 현재 "어떤 이메일을 넣어도 자동 통과"되는 테스트 코드를 지우고, DB에 존재하는 회원인지 검사하는 로직으로 변경해야 합니다.
- [ ] **소셜 로그인 API 연동:** 카카오, 네이버, 구글 로그인을 위해 각 개발자 센터에서 발급받은 '진짜 API 키'를 환경변수(`.env`)에 입력해야 합니다.

## 2. 💳 결제 및 주문 시스템 연동
- [ ] **진짜 PG사(결제대행사) 연동:** 무통장입금, 신용카드 결제를 받기 위해 토스페이먼츠(Toss), 포트원(PortOne), 이니시스 등의 결제 모듈을 붙여야 합니다.
- [ ] **네이버페이 버튼 실제 연동:** 상품 상세페이지의 '네이버페이 간편구매' 버튼이 실제 네이버페이 결제창으로 넘어가도록 네이버페이 센터(가맹점) API를 연동해야 합니다.
- [ ] **주문 내역(Order) DB 저장:** 결제가 완료된 후, 회원의 마이페이지와 관리자 페이지에서 주문 내역을 볼 수 있도록 데이터베이스에 주문 기록을 남겨야 합니다.

## 3. 🗄️ 데이터베이스 및 서버 환경 (호스팅)
- [ ] **운영용 데이터베이스 구축:** 현재 개발용 DB에서, Vercel Postgres, Supabase, AWS RDS 등 안정적인 상용 클라우드 데이터베이스로 전환해야 합니다.
- [ ] **보안 환경변수 설정:** `NEXTAUTH_SECRET`, `ADMIN_PASSWORD`, `DATABASE_URL` 등 중요한 비밀번호나 키값들을 배포 서버(예: Vercel 설정)에 안전하게 등록해야 합니다.

## 4. 🛠️ 관리자(Admin) 권한 및 보안
- [ ] **관리자 로그인 보안 강화:** 현재 하드코딩된 'admin123' 등의 임시 비밀번호를 삭제하고, 데이터베이스에서 관리자 권한을 가진 특정 계정만 `/admin` 페이지에 접근할 수 있도록 보안을 강화해야 합니다.
- [ ] **이미지 스토리지 적용:** 관리자 페이지에서 상품 이미지를 업로드할 때, AWS S3나 Vercel Blob 같은 클라우드 저장소에 이미지가 저장되도록 연동해야 합니다. (현재는 로컬이나 Placeholder 임시 주소 위주)

## 5. 🌐 마케팅 및 기타 설정
- [ ] **이메일 발송 시스템 설정:** 회원가입 환영 메일이나, 주문 완료 이메일 발송이 필요하다면 AWS SES나 SendGrid 등을 연동해야 합니다.
- [ ] **SEO(검색엔진 최적화) 등록:** 구글, 네이버 등에서 쇼핑몰이 검색될 수 있도록 `sitemap.xml`, `robots.txt` 설정 및 네이버 웹마스터 도구에 사이트를 등록해야 합니다.
- [ ] **진짜 이메일/고객센터 주소 기입:** 상품 상세 화면의 '메일보내기' 버튼에 연결된 주소(`contact@haniltrans.com`)를 실제 고객센터 이메일로 변경해야 합니다.
